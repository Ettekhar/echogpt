API Reference & Assignment Compliance

EchoGPT NestJS Backend · PostgreSQL · Swagger

Swagger Docs Postman
1. Authentication
  • POST /auth/register Bcrypt hash
  • POST /auth/login JWT Access+Refresh
  • POST /auth/refresh Token rotation
  • POST /auth/logout Invalidate session
2. User Management
  • GET /users/me Profile
  • PATCH /users/me Update details
  • PATCH /users/me/password Change pw
  • DELETE /users/me Delete account
3. Subscriptions
  • GET /subscriptions/status Current plan
  • GET /subscriptions/usage Quota info
  • PATCH /subscriptions/plan Free/Premium
  • Daily request enforcement
4. AI Providers
  • OpenAI, Claude, Gemini
  • POST /providers AES-256-GCM encrypt
  • POST /providers/:id/health-check
  • Enable / Disable / Default model
5. Chat & Streaming
  • POST /chat/messages AI response
  • POST /chat/messages/stream SSE
  • GET /chat/conversations History
  • Multi-turn context
6. Web Search
  • POST /search/query AI summary
  • GET /search/history Logs
  • GET /search/suggestions Autocomplete
  • 30-min PostgreSQL cache
